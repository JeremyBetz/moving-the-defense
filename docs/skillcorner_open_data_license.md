# SkillCorner Open Data license and publication boundary

The official [SkillCorner Open Data repository](https://github.com/SkillCorner/opendata)
contains an [MIT License](https://github.com/SkillCorner/opendata/blob/master/LICENSE)
with `Copyright (c) 2020 SkillCorner`. The license permits use, modification,
publication, distribution, sublicensing, and sale provided the copyright and
permission notice accompany copies or substantial portions. The repository
README also asks users to credit SkillCorner.

For this project the scientific/publication policy is deliberately narrower
than the license permits:

- raw SkillCorner tracking and provider files remain under ignored `data/` or
  temporary local storage and are never committed;
- frame/player rows, anchor samples, trajectories, and reconstructive derived
  tables are not committed;
- public artifacts may include source, tests, protocol/configuration, hashes,
  aggregate match-level support counts, aggregate coefficients/intervals, and
  compact non-reconstructive figures; and
- any public report credits SkillCorner Open Data and preserves the MIT notice
  in acquisition/reproduction documentation.

Importing Kloppy does not copy its source. Kloppy 3.19.0 is separately licensed
under BSD-3-Clause. Any future copied or modified third-party source would need
its own notice and review; none was copied in this compatibility pass.
