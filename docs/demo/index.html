What this shows

  1. 1. Rapid reorganizationFind an increase in movement relative to teammates over one second.
  2. 2. Trajectory integrityExclude implausible tracking before football interpretation.
  3. 3. Ball alignmentDescribe how much of that movement is oriented toward the ball.
  4. 4. Off-ball contextInspect concurrent attacker movement and qualifying spatial links.

The team measure is the mean trailing two-second defender-relative path across ten outfield defenders, in metres. A large value is not a rating of defending. These are fixed review examples, not a live analysis service.

Retrospective centered smoothing needs tracking through 0.12 seconds after the displayed time. Each clip adds five seconds of visual context on either side; selected measurements still use their frozen intervals. The fixed 0–6.25 m colour ceiling affects display only; larger raw values remain unchanged. A reference percentile shown in a clip is descriptive context, not a probability or performance rating. Clip source span: 10.00 s; encoded GIF duration: 10.08 s.

Paper versus demo

The paper studies off-ball movement direction and localized defensive reorganization using frozen scientific evidence. This demo is a separate exploratory application. Its illustrative passages add no inferential evidence and establish no causal or tactical mechanism.

Reproduce and inspect

Repository · README · Reproduce the paper · Technical API and demo guide · Paper submission candidate

From the reviewed application checkout, build the data-free local review with:

.venv/bin/python src/run_match_reorganization_demo.py --game 2 --output-dir review-output --no-media

The API guide documents the public Metrica prerequisites and bounded media route. This static export needs only the already-verified presentation package, not tracking files. Inspect public provenance and hashes.

Tracking data: Metrica Sports sample data. Animation rendered by Moving the Defense; no original match video is included. These tracking-derived images permit approximate positional recovery; they are not anonymized raw data or a general redistribution grant.
