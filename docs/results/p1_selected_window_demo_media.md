## Boundary and consistency

Only the five explicitly authorized Home examples are hydrated from closed
manifests. The demo no longer invokes candidate ranking or emits the former
25-record candidate overview. No scanner, reference-population construction,
event reconstruction or new selection is called.

The two public Game 2 tracking CSVs are streamed for source hashes and clock
filtering. Only coordinates inside each selected `[t−7.12,t+5.12]` support
slice are normalized. No Game 1, event file, Game 3, IDSSE, SkillCorner, DRD,
protected outcome or sibling repository is opened by this workflow.
Continuous marker colours within these slices are visual context, not new
candidate evaluation. Selected measures retain the original `[t−2,t]` interval.

All five recoveries agree with closed team levels, one-second changes,
integrity statuses, ballward shares, signed alignment and strata. Evaluated
attacker categories, counts and maximum paths agree too. Numeric tolerance is
absolute `1e-8`, relative `1e-9`. Identity and categorical checks are exact.
Percentiles and possession/context are copied from the closed authority, not
independently recomputed; overlapping closed records are checked for agreement.
Mismatch stops before any media is rendered. Failed integrity prevents
attacker-link construction.

## Local derivative and reproduction

`selected_window_cache.json` contains episode-local labels, contribution
magnitudes, the full strong-link list needed for the display cap, source and
code/config/reference hashes, raw/render/score bounds, integrity counts and
consistency status. It contains no coordinates, stable player identities or
raw tracking rows. It is an application/demo derivative, not a scientific
result or selection input; neither it nor generated media is committed.

Use the [documented demo command](../replay_scoring_api.md). `--no-media`
works with an absent data root. `--render-media` needs only the two hash-pinned
Game 2 tracking files. New output destinations are required; existing ones
fail closed. All generated artifacts remain local and movable together.
